### Equiv Directory Overview

This directory provides the theory of type equivalences in HoTT style.

- **`Fiber.md`**: Contractible fibers characterization — `hasContrFibers`, `contrFibers=>Equiv`, `Equiv=>contrFibers`.
- **`HalfAdjoint.md`**: Half-adjoint equivalences — `HAEquiv` class with coherence, coercion from `QEquiv`, propositionality.
- **`Path.md`**: Path-related equivalences — `pathEquiv`, `pathConcatEquiv`, `pmapEquiv`, `pmapEmbedding`, `pmapSection`.
- **`Sigma.md`**: Sigma-type equivalences — contractibility lemmas (`lsigma`, `rsigma`, `contr-left`, `contr-right`), `equiv=`, pi-contraction, sigma functoriality (`sigma-left`, `sigma-right`, `sigma-equiv`), `totalEquiv`.
- **`Univalence.md`**: Univalence — `=-to-Equiv`, `QEquiv-to-=`, `Equiv-to-=`, `univalence`.
