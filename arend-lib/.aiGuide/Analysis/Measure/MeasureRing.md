### Analysis.Measure.MeasureRing

Measure rings: Boolean rings equipped with a non-negative, countably-additive (here: finitely additive and monotone) measure function valued in upper reals, giving a topological abelian group structure.

#### Premeasure Rings

- **`PremeasureRing`**: Extends `BooleanRing` and `TopAbGroup`. A Boolean ring with a measure `meas : E -> ExUpperReal` satisfying `meas 0 = 0`, non-negativity, finite additivity on disjoint elements (`x * y = 0`), and monotonicity. The induced topology has open sets characterized by `meas`-balls: `U` is open iff for every `x ∈ U` there exist `a : E` and `eps > 0` such that `(meas (a * (x + y))).U eps` implies `y ∈ U`.
- **`meas`**: The measure function `E -> ExUpperReal`.
- **`meas_zro`**: `meas 0 = 0`.
- **`meas>=0`**: `0 <= meas x`.
- **`meas-disjoint`**: Finite additivity: `x * y = 0 -> meas (x ∨ y) = meas x + meas y`.
- **`meas-mono`**: Monotonicity: `x <= y -> meas x <= meas y` (derived from disjoint additivity via Boolean splitting).
- **`meas_+`**: Subadditivity: `meas (x + y) <= meas x + meas y` (derived from `+_diff` and disjointness of differences).
- **`isOpen`**, **`open-top`**, **`open-inter`**, **`open-Union`**: The topology generated by `meas`-balls and its closure properties.
- **`+-cont`**: Continuity of addition with respect to the measure-induced topology.

#### Ball Lemmas

- **`meas-<=<-ball`**: For `x <=< U` (well-inside relation), there exist `a`, `eps > 0` such that the open ball `OBall a eps x ⊆ U`. Bridges the cover-space well-inside relation with the measure-ball basis.

#### Measure Rings (Separated)

- **`MeasureRing`**: Extends `PremeasureRing` and `SeparatedCoverSpace`. Adds the separation axiom `meas-ext`: `meas x = 0 -> x = 0`. The class derives `isSeparatedCoverSpace` from `meas-ext` (using `meas_+` and Boolean identities to bound `meas (x - y)` by an arbitrarily small `b`), and conversely derives `meas-ext` from separation via `meas-<=<-ball`.
- **`meas-ext`**: Faithfulness of `meas`: `meas x = 0 -> x = 0`.

#### Modularity and Cauchy Characterization

- **`meas-modular`**: Inclusion-exclusion / modular law: `meas x + meas y = meas (x ∨ y) + meas (x ∧ y)`.
- **`cauchyFilter-measure-char`**: A filter `F` is Cauchy iff for every `a : X` and every `eps > 0` there exists `x : X` with `F (OBall a eps x)`. Reduces Cauchy-ness in the cover-space sense to measure-ball coverings.

#### Complete Measure Rings

- **`CompleteMeasureRing`**: Extends `MeasureRing` and `CompleteTopAbGroup`. A measure ring in which every proper filter satisfying the measure-Cauchy condition has a limit.
- **`isCompleteMeasure`**: Completeness phrased directly via measure balls: any proper filter `F` with `∀ a {eps > 0}, ∃ x, F (OBall a eps x)` admits a limit point `x` such that `F (OBall a eps x)` for all `a` and `eps > 0`.
- **`isComplete`**: Derived from `isCompleteMeasure` using `cauchyFilter-measure-char` and `meas-<=<-ball`, showing the two notions of completeness coincide.
