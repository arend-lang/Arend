### Analysis.Measure.SimpleFunctions

Simple (step) functions valued in an additive monoid `V`, indexed by elements of a bottom distributive lattice `B`, used as the building blocks for measure-theoretic integration.

A simple function is presented as a finite list of pairs `(v, b) : V × B`, intuitively meaning "the value `v` is taken on the region `b`". The list is quotiented by an inductive equivalence `~` that imposes the expected algebraic relations: zero coefficients/regions can be dropped, two pairs sharing a region add their values, and two pairs sharing a value combine their regions via join/meet. On top of this quotient, the module builds a tower of algebraic structures (abelian monoid, abelian group, rational module, ordered module, Riesz space). The order theory and Riesz structure are obtained by introducing a *reduction* procedure (`SFuncRepr.reduce`/`SFuncRepr.add`) that puts a list into a canonical "disjoint regions" form via the lattice difference, plus a refinement relation `SFuncRepr.SFRefines` linking two presentations; refinements provide the technical glue for proving inequalities and antisymmetry on the quotient.

#### Core Type and Equivalence

- **`SFunc V B`**: The type of simple functions as `Quotient` of `Array (Σ V B)` by `~`.
- **`~`**: Inductive equivalence on lists of pairs, generated by permutation, symmetry, transitivity, dropping zero-value or bottom-region entries, merging pairs with equal region (`(u,b) :: (v,b) :: l ~ (u+v,b) :: l`), and merging pairs with equal value via lattice join/meet (`(v,a∨b) :: (v,a∧b) :: l ~ (v,a) :: (v,b) :: l`).
- **`inSF`**: Constructor `Array (Σ V B) -> SFunc V B` (the quotient embedding).
- **`~_Equivalence`**: `~` is an equivalence relation.
- **`~-sfequiv`**: Lifts `l ~ l'` to `inSF l = inSF l'`.

#### Congruences for `~`

- **`~_++-left`**, **`~_++-right`**, **`~_++`**: Concatenation respects `~` on either side or both.
- **`~_::`**, **`~_::_=`**: Cons respects `~`, optionally allowing the head to vary by an equality.
- **`~-swap`**: `x :: y :: l ~ y :: x :: l`.
- **`~_+'`**, **`~_+`**: Combine two parallel lists sharing regions (resp. two functions on the same list) into a single list of sums.
- **`~-zros-left`**: A list whose values are all zero is `~ nil`.

#### Algebraic Structure

- **`SFuncAbMonoid`**: `AbMonoid` instance with `zro = inSF nil` and `+` defined by list concatenation, lifted through both quotient arguments.
- **`SFuncAbMonoid.*n-char`**: Characterizes the natural-number scalar action: `n *n inSF l = inSF (map (n *n ·, ·) l)`.
- **`SFuncAbGroup`**: `AbGroup` instance over an `AddGroup V`; `negative` is defined by negating each value componentwise.
- **`SFuncAbGroup.~_negative`**, **`~_negative-left`**, **`*i-char`**: Compatibility of negation with `~`, the inverse law, and characterization of the integer scalar action.
- **`SFuncQModule`**: `QModule` instance over a `QModule V`, built from a `LModule RatField` whose action is `q *c inSF l = inSF (map (q *q ·, ·) l)`.
- **`SFuncQModule.module`**, **`~_*q`**, **`*q-char`**: The underlying rational module, compatibility of rational scaling with `~`, and the action characterization.
- **`SFuncPosetQModule`**: `PosetQModule` instance on `SFunc V B` over a `PosetQModule V` and a `BooleanRing B`, built on `SFuncQModule` with the order `SFuncPosetQModule.<=` defined below.

#### Order: `SFuncPosetQModule`

Built over a `PosetQModule V` and a `BooleanRing B` (where the lattice is also a Boolean ring, so set difference `B.diff` is available). The reduction machinery below lives in `SFuncRepr` (over an `AbMonoid V` and a `BooleanRing B`) and is opened here.

- **`SFuncRepr`**: Representations of simple functions by finite families: an abbreviation for `Array (Σ V B)` over an `AbMonoid V` and a `BooleanRing B`, whose `\where` block holds the reduction to pairwise disjoint families, the refinement relation and their lemmas.

- **`SFuncPosetQModule.PFunc`**: Private abbreviation for `Array (Σ V B)`.
- **`SFuncPosetQModule.<=`**: `x <= y` iff there exists a list `l` with `y - x = inSF l` and all values in `l` are `≥ 0`.
- **`SFuncRepr.add`**: `add v b l` is the list `(v, b \ ⋁ regions of l) :: [(v + s.1, b * s.2)] ++ [(s.1, s.2 \ b)]` (over the entries `s` of `l`): the value `v` is added on the region `b`, which is split along the regions of `l`.
- **`SFuncRepr.reduce`**: Folds a list with `add` (`reduce (x :: l) = add x.1 x.2 (reduce l)`), producing a list with pairwise-disjoint regions.
- **`SFuncRepr.reduce-closed`**, **`SFuncPosetQModule.reduce_>=0`**, **`SFuncPosetQModule.reduce_<=0`**: If all values of `l` satisfy a predicate containing `0` and closed under `+`, so do all values of `reduce l`; in particular `reduce` preserves nonnegativity and nonpositivity of values.
- **`SFuncRepr.add_EPerm`**, **`SFuncRepr.reduce_EPerm`**: `add` and `reduce` respect extensional permutations.
- **`SFuncRepr.add_BigJoin`**, **`SFuncRepr.reduce_BigJoin`**: The join of all regions is preserved by `add` (up to `b ∨ ·`) and by `reduce` exactly.
- **`SFuncRepr.add-double`**, **`SFuncRepr.add-comm`**: Two nested `add`s expand to an explicit symmetric form, hence commute up to `EPerm`.

#### Refinement Relation

- **`SFuncRepr.SFRefines`**: `SFRefines l l'` says `l` refines `l'` when every entry of `l'` either has zero value or its region lies within the join of regions of `l`, and every entry of `l` has a counterpart in `l'` with equal value and larger region.
- **`SFuncRepr.SFRefines-refl`**, **`SFuncRepr.SFRefines_++`**, **`SFuncRepr.SFRefines_::`**, **`SFuncRepr.SFRefines_::-merge`**, **`SFuncRepr.SFRefines_++-merge`**, **`SFuncRepr.SFRefines-trans`**, **`SFuncRepr.SFRefines-swap`**, **`SFuncRepr.SFRefines_EPerm`**: Structural lemmas about `SFRefines`: reflexivity, compatibility with `++` and `::`, merging two entries of equal value into one over the join of their regions, transitivity (when the last list is reduced), swapping two heads, and `EPerm`-equivalent lists refine each other.
- **`SFuncRepr.SFRefines_++-left`**, **`SFuncRepr.SFRefines_++-right`**, **`SFuncRepr.SFRefines_::-right`**, **`SFuncRepr.SFRefines_add_0`**: Extending the coarser side: if `l` refines `r` and every new entry is zero-valued or has region inside the join of regions of `l`, then `l` refines the extended list; `SFRefines_add_0` states that `l` refines `add v 0 l`.
- **`SFuncRepr.SFRefines-closed`**: If `l` refines `l'` and all values of `l'` satisfy `P` (with `P 0`), then all values of `l` satisfy `P`.
- **`SFuncRepr.SFRefines-common`**: Given reduced lists `b`, `c` that both refine a reduced list `d`, produces a reduced list refining both `b` and `c` (the technical heart of antisymmetry).

#### Reduced Lists

- **`SFuncRepr.IsReducedB`**: An array of regions is reduced when any two entries at distinct indices have product (meet) `0`.
- **`SFuncRepr.IsReduced`**: Lifted to `PFunc` via the regions.
- **`SFuncRepr.add_IsReducedB`**, **`SFuncRepr.add_IsReduced`**, **`SFuncRepr.reduce_IsReduced`**: `add` applied to a reduced list gives a reduced list (on regions: `b \ ⋁ l :: map (b ∧) l ++ map (· \ b) l` is reduced when `l` is), hence `reduce l` is always reduced.

#### Equality on the Quotient

- **`SFuncRepr.~-unequals`**: For `l ~ l'`, there is a reduced list refining both `reduce l` and `reduce l'`.
- **`SFuncRepr.~-unequals.split`**, **`SFuncRepr.~-unequals.split_IsReduced`**, **`SFuncRepr.~-unequals.split_SFRefines`**, **`SFuncRepr.~-unequals.split_add_SFRefines`**, **`SFuncRepr.~-unequals.add0_~`**, **`SFuncRepr.~-unequals.add-double1`**, **`SFuncRepr.~-unequals.add_+_SFRefines`**, **`SFuncRepr.~-unequals.add-double2`**, **`SFuncRepr.~-unequals.add-modularity_SFRefines`**: Internal toolkit used to prove `~-unequals`: `split b l` cuts every region of `l` into its parts inside and outside `b`; `add 0 b l ~ l` and `add (u + v) b l` refines `add u b (add v b l)` for reduced `l`; `add v a (add v b l)` refines `add v (a ∨ b) (add v (a * b) l)` (modularity); `add-double1` and `add-double2` expand the corresponding double `add`s up to `EPerm`.
- **`SFuncRepr.~_=-unequals`**: Same conclusion from an equality `inSF l = inSF l'`.
- **`SFuncRepr.split1`**: Splits a single pair via a region: `(v,b) :: l ~ (v, c*b) :: (v, b\c) :: l`.
- **`SFuncRepr.reduced-tail`**, **`SFuncRepr.add_~`**, **`SFuncRepr.reduce_~`**: Reduction lemmas: tails of reduced lists are reduced, `add v b l ~ (v,b) :: l` when `l` is reduced, and `reduce l ~ l` for every `l`.
- **`SFuncRepr.~-+s-left`**: A reduced list whose values all equal `x.1` and whose regions have join `x.2` is `~ x :: nil`.
- **`SFuncRepr.SFRefines_~`**: Two reduced lists with `SFRefines l l'` are already `~`-equivalent.
- **`SFuncRepr.makeReduced`**: Every `SFunc` is `inSF l` for some reduced list `l`.

#### Order Characterization

- **`SFuncPosetQModule.>=0-reduced-char`**: For reduced `l`, `0 <= inSF l` iff every entry has nonnegative value or zero region; with helpers `SFuncPosetQModule.>=0-reduced-char.reduce-values`, `reduce-values-conv`, `reduce_>=0-conv`, `SFRefines_>=0-left`, `SFRefines_>=0-right`, `~_zro` (entries of `reduce l` come from `l` or have zero region and conversely; nonnegativity passes down along `SFRefines`; lists of equal length agreeing up to zero regions are `~`).
- **`SFuncRepr.~-common`**: Any finite family of presentations can be put into a common region pattern, i.e. all expressed over the same reduced region list `bs`.
- **`SFuncRepr.~-common.merge`**: Inductive step adding one more list to a common region pattern.
- **`SFuncPosetQModule.<=-common-char`**: With both sides over a common reduced region list `bs`, `<=` reduces to pointwise comparison of values (modulo zero regions).
- **`SFuncPosetQModule.<=-char`**: Global characterization of `<=` via existence of a common reduced region list and pointwise value inequality.

#### Functorial Lemmas and `RieszSpace`

- **`SFuncRepr.reduce_SFRefines`**, **`SFuncRepr.~-unequals-reduced`**, **`SFuncRepr.~_=-unequals-reduced`**, **`SFuncRepr.~-unequals-conv`**, **`SFuncRepr.~-unequals-reduced-conv`**: Bidirectional dictionary between `~`/equality on the quotient and existence of refining lists.
- **`SFuncRepr.SFRefines_apply-left`**, **`SFuncRepr.apply-left`**: Applying any function `f : V -> V` with `f 0 = 0` to all values respects refinement and `~`; lets one push pointwise operations through the quotient.
- **`SFuncRieszSpace`**: `RieszSpace` instance over a `RieszSpace V` and `BooleanRing B`, built via `RieszSpace.fromAbs` using pointwise `V.abs`. For a reduced `l`, `SFuncRieszSpace.isAbs` shows that `inSF (map (V.abs ·, ·) l)` is the least upper bound of `inSF l` and its negative (nonnegativity of `|v| - v` and `|v| + v` is checked entrywise, minimality via `SFuncPosetQModule.<=-char`), and `SFuncRieszSpace.abs-reduced` identifies it with the lattice `abs`.
- **`SFuncTruncRieszSpace`**: `TruncRieszSpace` instance on `SFunc V B` over a `TruncRieszSpace V` and a `BooleanRing B`, extending `SFuncRieszSpace`; `trunc` is applied pointwise to the values of a reduced presentation (`SFuncTruncRieszSpace.trunc-reduced`), and `SFuncTruncRieszSpace.trunc-assoc-helper` is the technical step of `trunc-assoc` via a common region pattern.
