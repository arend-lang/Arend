### Analysis.Measure.SimpleFunctions

Simple (step) functions valued in an additive monoid `V`, indexed by elements of a bottom distributive lattice `B`, used as the building blocks for measure-theoretic integration.

A simple function is presented as a finite list of pairs `(v, b) : V × B`, intuitively meaning "the value `v` is taken on the region `b`". The list is quotiented by an inductive equivalence `~` that imposes the expected algebraic relations: zero coefficients/regions can be dropped, two pairs sharing a region add their values, and two pairs sharing a value combine their regions via join/meet. On top of this quotient, the module builds a tower of algebraic structures (abelian monoid, abelian group, rational module, ordered module, Riesz space). The order theory and Riesz structure are obtained by introducing a *reduction* procedure (`reduce`/`add`) that puts a list into a canonical "disjoint regions" form via the lattice difference, plus a refinement relation `SFRefines` linking two presentations; refinements provide the technical glue for proving inequalities and antisymmetry on the quotient.

#### Core Type and Equivalence

- **`SFunc V B`**: The type of simple functions as `Quotient` of `Array (Σ V B)` by `~`.
- **`~`**: Inductive equivalence on lists of pairs, generated by permutation, symmetry, transitivity, dropping zero-value or bottom-region entries, merging pairs with equal region (`(u,b) :: (v,b) :: l ~ (u+v,b) :: l`), and merging pairs with equal value via lattice join/meet (`(v,a∨b) :: (v,a∧b) :: l ~ (v,a) :: (v,b) :: l`).
- **`inSF`**: Constructor `Array (Σ V B) -> SFunc V B` (the quotient embedding).
- **`~_Equivalence`**: `~` is an equivalence relation.
- **`~-sfequiv`**: Lifts `l ~ l'` to `inSF l = inSF l'`.

#### Congruences for `~`

- **`~_++-left`**, **`~_++-right`**, **`~_++`**: Concatenation respects `~` on either side or both.
- **`~_::`**, **`~_::_=`**: Cons respects `~`, optionally allowing the head to vary by an equality.
- **`~-swap`**: `x :: y :: l ~ y :: x :: l`.
- **`~_+'`**, **`~_+`**: Combine two parallel lists sharing regions (resp. two functions on the same list) into a single list of sums.
- **`~-zros-left`**: A list whose values are all zero is `~ nil`.

#### Algebraic Structure

- **`SFuncAbMonoid`**: `AbMonoid` instance with `zro = inSF nil` and `+` defined by list concatenation, lifted through both quotient arguments.
- **`SFuncAbMonoid.*n-char`**: Characterizes the natural-number scalar action: `n *n inSF l = inSF (map (n *n ·, ·) l)`.
- **`SFuncAbGroup`**: `AbGroup` instance over an `AddGroup V`; `negative` is defined by negating each value componentwise.
- **`SFuncAbGroup.~_negative`**, **`~_negative-left`**, **`*i-char`**: Compatibility of negation with `~`, the inverse law, and characterization of the integer scalar action.
- **`SFuncQModule`**: `QModule` instance over a `QModule V`, built from a `LModule RatField` whose action is `q *c inSF l = inSF (map (q *q ·, ·) l)`.
- **`SFuncQModule.module`**, **`~_*q`**, **`*q-char`**: The underlying rational module, compatibility of rational scaling with `~`, and the action characterization.

#### Order: `SFuncPosetQModule`

Built over a `PosetQModule V` and a `BooleanRing B` (where the lattice is also a Boolean ring, so set difference `B.diff` is available).

- **`PFunc`**: Abbreviation for `Array (Σ V B)`.
- **`<=`**: `x <= y` iff there exists a list `l` with `y - x = inSF l` and all values in `l` are `≥ 0`.
- **`add v b l`**: Inserts a pair `(v, b)` into `l` while subtracting `b` from previous regions, producing a list whose `B`-components are pairwise disjoint after combining with `l`.
- **`reduce`**: Iterates `add` over a list to put it into a canonical reduced form with pairwise-disjoint regions.
- **`reduce-closed`**, **`reduce_>=0`**, **`reduce_<=0`**: Reduction preserves predicates closed under `0` and `+`, and preserves nonnegativity/nonpositivity of values.
- **`add_EPerm`**, **`reduce_EPerm`**: `add` and `reduce` respect extensional permutations.
- **`add_BigJoin`**, **`reduce_BigJoin`**: The join of all regions is preserved by `add` (up to `b ∨ ·`) and by `reduce` exactly.
- **`add-double`**, **`add-comm`**: Two nested `add`s expand to an explicit symmetric form, hence commute up to `EPerm`.

#### Refinement Relation

- **`SFRefines l l'`**: `l` refines `l'` when every entry of `l'` either has zero value or its region lies within the join of regions of `l`, and every entry of `l` has a counterpart in `l'` with equal value and larger region.
- **`SFRefines-refl`**, **`SFRefines_++`**, **`SFRefines_::`**, **`SFRefines_::-merge`**, **`SFRefines_++-merge`**, **`SFRefines-trans`** (under reduction), **`SFRefines-swap`**, **`SFRefines_EPerm`**: Standard structural lemmas about `SFRefines`.
- **`SFRefines_++-left`**, **`SFRefines_++-right`**, **`SFRefines_::-right`**, **`SFRefines_add_0`**: Relating refinement with extensions of one side.
- **`SFRefines-closed`**: Refinement transports `0`-closed predicates from the larger side to the smaller.
- **`SFRefines-common`**: Given two reduced refinements of a common `d`, produces a common reduced refiner of both (the technical heart of antisymmetry).

#### Reduced Lists

- **`IsReducedB`**: A list of regions is reduced when any two distinct entries meet to `0`.
- **`IsReduced`**: Lifted to `PFunc` via the regions.
- **`add_IsReducedB`**, **`add_IsReduced`**, **`reduce_IsReduced`**: `add`/`reduce` produce reduced lists.

#### Equality on the Quotient

- **`~-unequals`**: For `l ~ l'`, there is a reduced list refining both `reduce l` and `reduce l'`.
- **`~-unequals.split`**, **`split_IsReduced`**, **`split_SFRefines`**, **`split_add_SFRefines`**, **`add0_~`**, **`add-double1`**, **`add_+_SFRefines`**, **`add-double2`**, **`add-modularity_SFRefines`**: Internal toolkit (splitting by a region, modularity in the join/meet of regions) used to prove `~-unequals`.
- **`~_=-unequals`**: Same conclusion from an equality `inSF l = inSF l'`.
- **`split1`**: Splits a single pair via a region: `(v,b) :: l ~ (v, c*b) :: (v, b\c) :: l`.
- **`reduced-tail`**, **`add_~`**, **`reduce_~`**: Reduction lemmas: tails of reduced lists are reduced, `add v b l ~ (v,b) :: l` when `l` is reduced, and `reduce l ~ l`.
- **`~-+s-left`**: Collapses a reduced list with constant value into a single pair.
- **`SFRefines_~`**: Two reduced lists with `SFRefines l l'` are already `~`-equivalent.
- **`makeReduced`**: Every `SFunc` is represented by some reduced list.

#### Order Characterization

- **`>=0-reduced-char`**: For reduced `l`, `0 <= inSF l` iff every entry has nonnegative value or zero region; with helpers `reduce-values`, `reduce-values-conv`, `reduce_>=0-conv`, `SFRefines_>=0-left`, `SFRefines_>=0-right`, `~_zro`.
- **`~-common`**: Any finite family of presentations can be put into a common region pattern, i.e. all expressed over the same reduced region list `bs`.
- **`~-common.merge`**: Inductive step adding one more list to a common region pattern.
- **`<=-common-char`**: With both sides over a common reduced region list, `<=` reduces to pointwise comparison of values (modulo zero regions).
- **`<=-char`**: Global characterization of `<=` via existence of a common reduced region list and pointwise value inequality.

#### Functorial Lemmas and `RieszSpace`

- **`reduce_SFRefines`**, **`~-unequals-reduced`**, **`~_=-unequals-reduced`**, **`~-unequals-conv`**, **`~-unequals-reduced-conv`**: Bidirectional dictionary between `~`/equality on the quotient and existence of refining lists.
- **`SFRefines_apply-left`**, **`apply-left`**: Applying any function `f : V -> V` with `f 0 = 0` to all values respects refinement and `~`; lets one push pointwise operations through the quotient.
- **`SFuncRieszSpace`**: `RieszSpace` instance over a `RieszSpace V` and `BooleanRing B`, built via `RieszSpace.fromAbs` using pointwise `V.abs`. Decomposes `a` as `|a| - a` and `|a| + a` (both nonnegative), and proves `|·|` monotone under `<=` by reducing to the common-region characterization.
