### Analysis.Measure.SimpleFunctions

Constructs simple functions over a Riesz space `V` with measurable predicates in a Boolean lattice `B`, represented as quotients of arrays of (value, predicate) pairs modulo permutation, splitting, and merging relations, and equips them with abelian group, Q-module, and Riesz space structures.

#### The `SFunc` Type and Equivalence Relation

- **`SFunc`**: The type of simple functions `Quotient (~)` over arrays of `(\Sigma V B)` pairs, parameterized by an additive monoid `V` and a bottom-distributive lattice `B`.
- **`~`**: The equivalence relation on raw arrays generated by permutations, zero-value/zero-predicate elimination, additivity in the value component (`~-+-left`), and modularity in the predicate component (`~-+-right`: `(v, a∨b) :: (v, a∧b) ↔ (v, a) :: (v, b)`).
- **`inSF`**: Embedding of an array into `SFunc V B` via the quotient map.
- **`~_Equivalence`**: Witness that `~` is reflexive, symmetric, and transitive.

#### Congruence Lemmas for `~`

- **`~-sfequiv`**: `l ~ l' → inSF l = inSF l'`.
- **`~_++-left`**, **`~_++-right`**, **`~_++`**: Compatibility of `~` with array concatenation.
- **`~_::`**, **`~_::_=`**: Compatibility of `~` with `cons`.
- **`~-swap`**: Adjacent swap is an `~`-equivalence.
- **`~_+'`**, **`~_+`**: Pointwise addition of value components combines two arrays sharing predicate parts.
- **`~-zros-left`**: An array whose values are all zero is `~`-equivalent to `nil`.

#### Abelian Monoid / Group Structure

- **`SFuncAbMonoid`**: `AbMonoid (SFunc V B)` with `zro = inSF nil` and `+` induced by concatenation; carries `*n-char` describing scalar `n`-fold addition.
- **`SFuncAbGroup`**: `AbGroup (SFunc V B)` extending `SFuncAbMonoid`, with negation acting pointwise on values.
  - **`~_negative`**: Pointwise negation respects `~`.
  - **`~_negative-left`**: `(-l) ++ l ~ nil`.
  - **`*i-char`**: Characterization of integer scalar action.

#### Q-Module Structure

- **`SFuncQModule`**: `QModule (SFunc V B)` over `RatField`, built from a rational `LModule` whose action `*c` distributes over the value component.
  - **`module`**: The underlying `LModule RatField`.
  - **`~_*q`**: Rational scalar multiplication respects `~`.
  - **`*q-char`**: `q *q inSF l = inSF (map (q V.*q ·, ·) l)`.

#### Order Structure (`PosetQModule`)

- **`SFuncPosetQModule`**: `PosetQModule (SFunc V B)` over a `BooleanRing` `B`, with `f <= g` defined as existence of a witness array `l` with all-nonnegative values such that `g - f = inSF l`.
  - **`<=`**: The order, witnessed by a non-negative difference.
  - **`PFunc`**: Abbreviation for `Array (\Sigma V B)`.
  - Reflexivity, transitivity, antisymmetry, additivity, and divisibility by nonzero `n` (`<=_*n-div`) are established.

#### Reduction to Disjoint Form

- **`add`**: Inserts a pair `(v, b)` into a list, splitting against the existing predicate-join so the result has more disjoint predicates.
- **`reduce`**: Iterated `add`, producing an array with pairwise-orthogonal predicates.
- **`reduce-closed`**, **`reduce-closed.add-closed`**: Predicates closed under `0` and `+` propagate through `reduce`/`add`.
- **`reduce_>=0`**, **`reduce_<=0`**: Sign of values is preserved by `reduce`.
- **`add_EPerm`**, **`reduce_EPerm`**: `add`/`reduce` respect extensional permutations of inputs.
- **`add_BigJoin`**, **`reduce_BigJoin`**: The `BigJoin` of predicates is preserved.
- **`add-double`**, **`add-comm`**, **`add-double1`**, **`add-double2`**: Permutation identities expanding nested `add` calls; basis for proving commutativity.

#### `IsReduced` and `SFRefines`

- **`IsReducedB`**: An array of predicates `l : Array B` with `l i * l j = 0` for `i ≠ j` (pairwise orthogonal).
- **`IsReduced`**: An array `l : PFunc` whose predicate components are `IsReducedB`.
- **`add_IsReducedB`**, **`add_IsReduced`**, **`reduce_IsReduced`**: `add`/`reduce` produce reduced arrays.
- **`SFRefines`**: A "refinement" relation `l ⊑ l'` saying every value in `l` matches some value in `l'` with `≤`-related predicate, and irrelevant predicates from `l'` are dominated by `l`.
- **`SFRefines-refl`**, **`SFRefines-trans`** (under reduction), **`SFRefines_EPerm`**: Order-theoretic structure of refinement.
- **`SFRefines_++`**, **`SFRefines_::`**, **`SFRefines_::-merge`**, **`SFRefines_++-merge`**, **`SFRefines-swap`**, **`SFRefines_++-left`**, **`SFRefines_++-right`**, **`SFRefines_::-right`**, **`SFRefines_add_0`**: Combinators for building refinements.
- **`SFRefines-closed`**: Predicates on values transfer along refinements.
- **`SFRefines-common`**: Two reduced arrays refining a common `d` admit a common reduced refinement of both.

#### Equality / Equivalence Decomposition

- **`~-unequals`**: `l ~ l'` iff their reductions admit a common reduced refinement.
- **`~-unequals.split`**, **`split_IsReduced`**, **`split_SFRefines`**, **`split_add_SFRefines`**: Splitting an array against a predicate `b`.
- **`~-unequals.add0_~`**: `add 0 b l ~ l` for reduced `l`.
- **`~-unequals.add_+_SFRefines`**, **`~-unequals.add-modularity_SFRefines`**: Refinement laws expressing the additive and modularity generators of `~`.
- **`~_=-unequals`**, **`~_=-unequals-reduced`**: From equality `inSF l = inSF l'` extract refinement data.
- **`~-unequals-reduced`**, **`~-unequals-conv`**, **`~-unequals-reduced-conv`**: Two-way bridges between `~` and refinement.
- **`split1`**: `(v, b) :: l ~ (v, c*b) :: (v, b\c) :: l` — splits a single entry.
- **`reduced-tail`**: Tail of a reduced array remains reduced.
- **`add_~`**: `add v b l ~ (v, b) :: l` when `l` is reduced.
- **`reduce_~`**: `reduce l ~ l`.
- **`~-+s-left`**: A reduced array all of whose values agree with `x.1` and whose predicate-join equals `x.2` is `~ x :: nil`.
- **`SFRefines_~`**: Two reduced arrays related by mutual refinement are `~`-equivalent.
- **`makeReduced`**: Every `SFunc` is represented by some reduced array.
- **`reduce_SFRefines`**: Reduced `l` refines into `reduce l`.

#### Common Refinement and `<=` Characterization

- **`~-common`**: Any finite collection of arrays admits a single reduced predicate basis `bs` and value matrices `vss` such that each array is `~` to the `(vss j i, bs i)` form.
- **`~-common.merge`**: Merging step combining a new array with an existing common refinement.
- **`<=-common-char`**: When two simple functions share predicate basis `bs`, `f <= g` iff each component value satisfies `vs j ≤ vs' j` (or the predicate is zero).
- **`<=-char`**: Full characterization of `<=` on `SFunc V B` via existence of a common reduced predicate basis with pointwise `<=`.

#### Non-negativity Characterization

- **`>=0-reduced-char`**: For reduced `l`, `0 <= inSF l` iff every component is non-negative or has a zero predicate.
  - **`reduce-values`**, **`reduce-values.aux`**, **`reduce-values-conv`**: Values produced by `reduce` either come from the input or have predicate zero.
  - **`reduce_>=0-conv`**: Reverse direction passing through `reduce`.
  - **`SFRefines_>=0-left`**, **`SFRefines_>=0-right`**: Non-negativity transfers along refinements.
  - **`~_zro`**: Two equal-length arrays whose entries either coincide or both have predicate `0` are `~`-equivalent.

#### Pointwise Function Application

- **`SFRefines_apply-left`**: Refinement is preserved under pointwise application of any `f : V → V` with `f 0 = 0`.
- **`apply-left`**: For reduced `~`-equivalent arrays, applying any zero-preserving `f : V → V` to value components preserves `~`.

#### Riesz Space Structure

- **`SFuncRieszSpace`**: `RieszSpace (SFunc V B)` over a `RieszSpace V` and `BooleanRing B`, built via `RieszSpace.fromAbs` from the pointwise absolute value on value components, using `~_+` and `apply-left` to verify the Riesz axioms (positivity of `|a| - a` and `|a| + a`, and the `|·|`-monotonicity property).
