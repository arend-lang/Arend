### Arith.Nat.EulerTotient

This module defines the Euler totient function and related algebraic structures connecting `Fin (suc n)` rings to quotient rings of integers.

#### Invertible Element Structures

- **`InvSubMonoid`**: `SubMonoid M` consisting of invertible elements of a monoid `M`.
- **`InvGroup`**: `Group` instance on the invertible elements of a monoid `M`, with inverse given by swapping an element and its inverse witness.

#### Coprime Elements of `Fin (suc n)`

- **`coPrimes`**: `FinSet` of elements `k : Fin (suc n)` such that `gcd(k, suc n) = 1`.
- **`coPrimes-eq`**: `QEquiv` between `coPrimes n` and `InvGroup (FinRing {n})`, showing coprime residues correspond to units.
  - **`finv-formula`**: Computes the modular inverse of `x` via the Bézout identity.
  - **`gcd-inv`**: Proves `x * finv-formula x = 1` in `Fin (suc n)` when `gcd(suc n, x) = 1`.

#### Euler Totient Function

- **`EulerTotient`**: `Nat`-valued function returning the cardinality of `coPrimes n` (i.e., `φ(n+1)`).

#### Quotient Ring Isomorphism

- **`ker-int-Coef`**: The kernel of the integer coefficient map `IntRing → FinRing {n}` equals the principal ideal generated by `suc n`.
- **`Z/nZ=FinRing`**: `Iso` between `FactorRing (closure1 (suc n))` (i.e., `ℤ/(n+1)ℤ`) and `FinRing {n}`.

#### Chinese Remainder Theorem Ingredients

- **`chinese-map`**: Maps `Fin (suc (suc n * m + n))` to the product `Fin (suc n) × Fin (suc m)` via modular reduction.
- **`natSemiring-unit`**: If `n` is invertible in `NatSemiring`, then `n = 1`.
- **`chinese-map-surj`**: `chinese-map` is surjective when `suc n` and `suc m` are coprime.
  - **`mod-inv`**: `x mod (n * m) mod n = x mod n` when `n ≠ 0`.
