### Homotopy.K1

The Eilenberg-MacLane space `K(G,1)` for a group `G`, presented as a higher inductive type, with a proof that its loop space recovers `G`.

`K1 G` is built as a 1-truncated higher inductive type with a single point `base`, a loop for each group element, and a 2-cell `relation` enforcing that the loop assignment is a group homomorphism (composition of loops corresponds to multiplication). The main theorem `Loop_K1` exhibits an equivalence `(base = base) = G` via the standard encode/decode method: the universal cover `code` sends each loop to right-multiplication as an equivalence on `G`, and the encode/decode functions assemble into an isomorphism. The functoriality of right-multiplication (`rMul-functorial`, `equivPathComposition`) is what makes `code` respect the `relation` 2-cell.

#### The Higher Inductive Type

- **`K1`**: The HIT defining `K(G,1)` as a `\1-Type`, with constructors `base`, `loop : G -> base = base`, and a square `relation g g'` whose four faces witness `loop g *> loop g' = loop (g * g')`.
- **`K1.loop-comp`**: Extracts from `relation` the homomorphism law `path (loop g) *> path (loop g') = path (loop (g * g'))` using the cube-equality characterization.
- **`K1.loop-ide`**: The loop at the identity is reflexivity: `path (loop ide) = idp`. Proved by cancelling `loop ide *> loop ide = loop ide` via the auxiliary `idp-lemma`.

#### Path Manipulation Helpers

- **`movePath1`**: Rearranges `p *> q = r` into `p = r *> inv q`.
- **`movePath2`**: Rearranges `p = r *> inv q` into `p *> q = r` (inverse of `movePath1`).

#### Group Action as Equivalences

- **`leftMulEquiv`**: `QEquiv (g *)` with inverse `inverse g *`; left-multiplication by `g` is an equivalence on `G`.
- **`rightMulEquiv`**: `QEquiv (* g)` with inverse `* inverse g`; right-multiplication by `g` is an equivalence on `G`.
- **`rMul-functorial`**: Functoriality of right-multiplication: `(\lam x => rightMulEquiv g' (rightMulEquiv g x)) = rightMulEquiv (g * g')`, by associativity.

#### Univalence and Functoriality

- **`=-to-Equiv-functorial`**: `=-to-Equiv (p *> q) = =-to-Equiv p `transEquiv` =-to-Equiv q`; the path-to-equivalence map respects composition.
- **`Equiv-to-=-functorial`**: The inverse direction: `Equiv-to-= e1 *> Equiv-to-= e2 = Equiv-to-= (e1 `transEquiv` e2)`, derived from univalence.
- **`equivFibr`**: The fibration of equivalences over the path `rMul-functorial g g'`, used to state composition of right-multiplications coherently.
- **`compToMult`**: Coherence path: `rightMulEquiv g `transEquiv` rightMulEquiv g'` agrees with `rightMulEquiv (g * g')` over `rMul-functorial`.
- **`equivPathComposition`**: The univalence-image equation `Equiv-to-= (rightMulEquiv g) *> Equiv-to-= (rightMulEquiv g') = Equiv-to-= (rightMulEquiv (g * g'))`, the key fact making `code` well-defined on `relation`.

#### The Universal Cover and the Encode/Decode Equivalence

- **`code`**: The universal cover `K1 G -> \Set` sending `base` to `G`, `loop g` to the path `Equiv-to-= (rightMulEquiv g)`, and `relation` to a 2-cell built from `equivPathComposition` via `Cube2.map`.
- **`encode`**: `(base = x) -> code x` defined by `transport code p ide`.
- **`decode`**: `code x -> (base = x)` sending `c : G` (at `base`) to `path (loop c)`; over `loop g` it uses the homomorphism law packaged as `decode_loop_homo`.
- **`decode.wind`**: Abbreviation `wind g = path (loop g) : base = base`.
- **`decode.decode_loop_homo`**: Transport coherence `transport (\lam x => code x -> base = x) (wind g) wind = wind`, ultimately from `K1.loop-comp`.
- **`encode_decode`**: `decode x (encode x p) = p`, by path induction reducing to `K1.loop-ide`.
- **`decode_encode`**: `encode x (decode x c) = c`, at `base` reducing to `ide-left`.
- **`Loop_K1`**: The main result: `(base {G} = base) = G`, packaging encode/decode into an iso. Witnesses that `K1 G` is an Eilenberg-MacLane space `K(G,1)`.
