### Homotopy.K1

The Eilenberg-MacLane space `K(G,1)` as a higher inductive 1-type, with a proof that its loop space recovers the group `G`.

#### The Higher Inductive Type

- **`K1`**: The Eilenberg-MacLane space `K(G,1)` for a group `G`, defined as a `\1-Type` with a basepoint `base`, a loop `loop g : base = base` for each group element, and a 2-cell `relation g g'` witnessing `loop g *> loop g' = loop (g * g')`.
- **`K1.loop-comp`**: `path (loop g) *> path (loop g') = path (loop (g * g'))`, extracting the group homomorphism property from the `relation` constructor.
- **`K1.loop-ide`**: `path (loop ide) = idp`, showing the identity element maps to the trivial loop.
- **`K1.loop-ide.idp-lemma`**: Auxiliary cancellation: if `q *> p = p` then `q = idp`.

#### Path Algebra Helpers

- **`movePath1`**: Rearranges `p *> q = r` into `p = r *> inv q`.
- **`movePath2`**: Rearranges `p = r *> inv q` into `p *> q = r` (inverse of `movePath1`).

#### Group Multiplication as Equivalences

- **`leftMulEquiv`**: For `g : G`, the equivalence `g * -` on `G` with inverse `inverse g * -`.
- **`rightMulEquiv`**: For `g : G`, the equivalence `- * g` on `G` with inverse `- * inverse g`.
- **`rMul-functorial`**: `rightMulEquiv g' ∘ rightMulEquiv g = rightMulEquiv (g * g')` as functions, by associativity.
- **`equivFibr`**: The dependent type `Equiv G G` over the path `rMul-functorial g g'`, used to express functoriality up to equivalence.
- **`compToMult`**: Functoriality of `rightMulEquiv`: composing the equivalences for `g` and `g'` equals the equivalence for `g * g'`.

#### Univalence and Functoriality

- **`=-to-Equiv-functorial`**: The map `=-to-Equiv` sends path concatenation to equivalence composition.
- **`Equiv-to-=-functorial`**: The univalence map `Equiv-to-=` sends equivalence composition to path concatenation.
- **`equivPathComposition`**: `Equiv-to-= (rightMulEquiv g) *> Equiv-to-= (rightMulEquiv g') = Equiv-to-= (rightMulEquiv (g * g'))`, the path-level statement of multiplicativity.

#### The Code Family and Loop Space Computation

- **`code`**: The type family `K1 G -> \Set` sending `base` to `G`, `loop g` to the path `Equiv-to-= (rightMulEquiv g)`, and the `relation` 2-cell to a square built from `equivPathComposition`. Used for the encode-decode argument.
- **`encode`**: `(p : base = x) -> code x`, defined by `transport code p ide`.
- **`decode`**: `code x -> base = x`, sending `c : G` over `base` to `path (loop c)` and extended over `loop g` via `decode_loop_homo`.
- **`decode.wind`**: Abbreviation for `path (loop g) : base = base`.
- **`decode.decode_loop_homo`**: The dependent path showing `wind` transports correctly along `wind g`, reducing to `loop-comp`.
- **`encode_decode`**: `decode x (encode x p) = p` for any `p : base = x`, by path induction using `K1.loop-ide`.
- **`decode_encode`**: `encode x (decode x c) = c`, by left-identity of group multiplication.
- **`Loop_K1`**: The main theorem: `(base = base) = G` as types, exhibiting `G` as the fundamental group of `K(G,1)`.
