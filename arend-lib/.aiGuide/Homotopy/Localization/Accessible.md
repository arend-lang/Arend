### Homotopy.Localization.Accessible

Constructs accessible reflective subuniverses and modalities from a small family of maps, including nullification at a family of types.

A localization is *accessible* when it is generated by a small family of maps `F j : X j -> Y j`: a type `Z` is local iff precomposition with each `F j` is an equivalence on `Y j -> Z`. The reflector is built as a higher inductive type `LData A` whose path constructor `isExt` forces every `F j` to become invertible. To obtain *uniqueness* of extensions (not just existence), the construction is repeated against an augmented family `famHat` that pairs each `F j` with the codiagonal of its pushout, which encodes path-equivalences and yields the full universal property. Nullification — quotienting by maps to the unit type — is recovered as the special case where each `Y j` is contractible.

#### The Family Abstraction

- **`Family`**: A class packaging a generating family of maps: index `J : \Type`, domain/codomain families `X, Y : J -> \Type`, and maps `F : \Pi (j : J) -> X j -> Y j`. A type is local w.r.t. this family when each `F j` is "invertible" against it.
- **`universe`**: Instance of `Universe` for a `Family`. A type `Z` is local iff `o F j : (Y j -> Z) -> (X j -> Z)` is an equivalence for every `j`.

#### The Localization HIT

- **`LData`**: Higher inductive type giving the localization of `A` at `fam`. Constructors:
  - `alpha`: unit map `A -> LData A`.
  - `ext`: extends a function `X j -> LData A` along `F j` to `Y j -> LData A`.
  - `isExt`: path constructor making `ext f (F j x) = f x`, ensuring extensions are sections of precomposition.
- **`dataExt`**: Recursion principle. Given `h : A -> Z` into a local type, produces `LData A -> Z` by using local-section data `sec` to interpret `ext` and `f_sec` to interpret `isExt`.
- **`dataExt-unique`**: Uniqueness of extensions. Two maps `H1, H2 : LData A -> Z` agreeing on `alpha` are equal everywhere; the proof uses the augmented family `famHat` so that the path-level coherence of `isExt` is itself extendable.

#### Universal Property

- **`alpha-equiv`**: The reflection equivalence `(LData A -> Z) ≃ (A -> Z)` given by precomposition with `alpha`, for any local `Z`. This is the defining universal property of the localization.
- **`famUniverse`**: Main constructor. Packages `universe` and the HIT into a `ReflUniverse`, providing for each `A` a `Localization` with reflector `LData` and unit `alpha`.

#### Augmented Family for Coherence

The augmented family `famHat` doubles each generator with its codiagonal so that the localization respects path-spaces, making the recursion principle into a genuine equivalence rather than just a section.

- **`DHat`**, **`CHat`**, **`FHat`**: Augmented domain, codomain, and map. For `inl j` they recover `F j`; for `inr j` they take the codiagonal `PushoutData (F j) (F j) -> Y j` (the canonical map sending both copies to identity).
- **`famHat`**: The augmented `Family` indexed by `J `Or` J` built from `DHat`, `CHat`, `FHat`. Locality w.r.t. `famHat` is equivalent to locality w.r.t. `fam` plus path-locality, which is what `dataExt-unique` needs.
- **`pushout_pullback-equiv`**: For `f : X -> Y`, `Σ (g1 g2 : Y -> Z) (g1 ∘ f = g2 ∘ f) ≃ (PushoutData f f -> Z)`. Used to identify locality at the codiagonal of `f` with the diagonal of `o f` being an embedding.

#### Nullification

- **`nullFamUniverse`**: Modality obtained by localizing at a family `X : J -> \Type`, viewed as maps `X j -> \Sigma` (the unit type). This *nullifies* each `X j`, making it contractible after reflection.
  - **`localDesc`**: `Z` is local for this modality iff for every `j`, the constant map `Z -> (X j -> Z)` is an equivalence — i.e. `X j -> Z` is essentially `Z`.
- **`nullTypeUniverse`**: Special case nullifying a single type `M`, giving the modality whose local types `Z` satisfy `Z ≃ (M -> Z)` via the constant map.
  - **`localDesc`**: Characterization of locality as the constant-map equivalence `Z ≃ (M -> Z)`.
