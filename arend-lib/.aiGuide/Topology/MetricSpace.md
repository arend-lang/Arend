### Topology.MetricSpace

Pseudo-metric and metric spaces with extended (possibly infinite) distances, and structure-preserving maps between them.

This module formalizes metric structures by layering them onto the existing uniform/cover space hierarchy. Distances take values in `ExUpperReal` (extended upper reals) for the general `ExPseudoMetricSpace`, and in `Real` for the stricter `PseudoMetricSpace`; the uniformity is generated by open balls via `dist-uniform`. Separation (`ExMetricSpace`/`MetricSpace`) is obtained by requiring `dist x y = 0 -> x = y`, and completeness is reformulated metrically through Cauchy filters that admit small balls. Maps come in a hierarchy — locally uniform, uniformly continuous, non-expanding (`MetricMap`), and isometric — each refining the previous via stronger distance conditions.

#### Pseudo-Metric Spaces

- **`ExPseudoMetricSpace`**: Extends `UniformSpace` with an extended-upper-real distance `dist : E -> E -> ExUpperReal` satisfying reflexivity, symmetry, and the triangle inequality. The uniformity is characterized by `dist-uniform`: a cover is uniform iff some `eps > 0` ball at every point refines it.
- **`dist-refl`**, **`dist-symm`**, **`dist-triang`**: The three metric axioms.
- **`dist-uniform`**: Equivalence between uniform covers and ball-refinement covers.
- **`metricProperUniform`**: The uniformity is proper.
- **`metricUniform`**: For any `eps > 0`, the family of `eps`-balls forms a uniform cover.
- **`NFilter`**: Neighborhood filter at `x`, generated by open balls around `x`.
- **`halving`**, **`halving-left`**, **`halving-right`**, **`halving1/2`**: Triangle-inequality lemmas combining two ball-membership facts (in various symmetric variants) into a single ball claim.
- **`PseudoMetricSpace`**: Refines `ExPseudoMetricSpace` to `Real`-valued distances and extends `StronglyRegularUniformSpace`; provides `uniform-strongly-star` via halving.

#### Open Balls and Distance Lemmas

- **`dist>=0`**: Distances are nonnegative.
- **`OBall`**: The open ball `OBall eps x = { y | dist x y < eps }`.
- **`OBall-center`**: `x` lies in its own `eps`-ball when `eps > 0`.
- **`OBall-open`**: Open balls are open in the induced topology.
- **`OBall-center_<=<`**: `{x}` is way-below `OBall eps x`.
- **`cauchy-ball`**: Every Cauchy cover contains a member that includes some ball around `x`.
- **`dist_open`**: A set is open iff every point has a ball inside it.
- **`<=<-ball`**: If `{x} <=< U` then some ball at `x` lies in `U`.
- **`OBall_<=*`**: Smaller balls star-refine larger ones.
- **`OBall_s<=*`**: Strong star-refinement variant for `PseudoMetricSpace`.
- **`IsBoundedSet`**: A set is bounded if some point in it is within distance `B` of all others.

#### Real-Valued Distances

- **`ldist`**, **`ldist>=0`**, **`ldist-refl`**, **`ldist-symm`**, **`ldist-triang`**: The `Real`-valued distance and its axioms restated for `PseudoMetricSpace`.

#### Continuity Characterizations

- **`metric-contAt-char`**: `epsilon`-`delta` characterization of continuity at a point using `ExUpperReal` ball membership.
- **`metric-contAt-real`**: `epsilon`-`delta` characterization using strict `Real` inequalities, for `PseudoMetricSpace`.

#### Separated and Complete Spaces

- **`ExMetricSpace`**: Extends `ExPseudoMetricSpace` and `SeparatedCoverSpace` by requiring `dist-ext : dist x y = 0 -> x = y`. The two separation conditions are shown equivalent.
- **`metric-ext`**: Two points are equal if every positive `eps`-ball around one contains the other.
- **`MetricSpace`**: Extends both `PseudoMetricSpace` and `ExMetricSpace`.
- **`CompleteMetricSpace`**: Extends `MetricSpace` with `StronglyCompleteUniformSpace`.
- **`CompleteExMetricSpace`**: Extends `ExMetricSpace` and `CompleteUniformSpace`, equipping completeness with a metric formulation `isCompleteMetric`: every Cauchy filter (containing arbitrarily small balls) converges to a unique point whose every ball is in the filter.
- **`cauchyFilter-metric-char`**: A filter is Cauchy iff for every `eps > 0` it contains some `eps`-ball.

#### Metric Maps

- **`LocallyUniformMetricMap`**: Extends `LocallyUniformMap` with `func-dist-locally-uniform`: a doubly-quantified `eps`/`delta`/`gamma` condition expressing local uniform continuity in metric terms. Includes constructors `fromLocallyUniformMap` and `makeLocallyUniformMap2` (for binary maps from products).
- **`UniformMetricMap`**: Extends `LocallyUniformMetricMap` and `UniformMap` with `func-dist-uniform`, the standard global `eps`-`delta` uniform continuity. Provides `fromUniformMap`.
- **`MetricMap`**: Extends `UniformMetricMap` with `func-dist`: a non-expanding (1-Lipschitz) map, `dist (f x) (f y) <= dist x y`.
- **`func-ldist`**: Real-valued non-expansion bound for `MetricMap`s between `PseudoMetricSpace`s.
- **`IsometricMap`**: Extends `MetricMap` with `func-isometry`: distances are preserved exactly. Provides `dense->uniformEmbedding`: a dense isometric map is a dense uniform embedding.
- **`func-lisometry`**: Real-valued isometry equation for `IsometricMap`s.

#### Transfer Constructions

- **`ExPseudoMetricTransfer`**: Pulls back an `ExPseudoMetricSpace` structure along an arbitrary function `f : X -> Y`.
- **`ExMetricTransfer`**: Pulls back an `ExMetricSpace` along an injection (injectivity gives `dist-ext`).
- **`PseudoMetricTransfer`**: `Real`-valued analogue of `ExPseudoMetricTransfer`.
- **`MetricTransfer`**: `Real`-valued analogue of `ExMetricTransfer` for `MetricSpace`.
