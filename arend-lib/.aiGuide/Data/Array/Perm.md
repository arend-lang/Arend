### Data.Array.Perm

Inductively-defined permutations between two arrays of equal length, with sign and equivalence-based reformulations.

This module defines `Perm l1 l2` as a higher inductive-style data type generated by the empty permutation, head-preserving step, adjacent swap, and transitivity. Because the swap constructor witnesses a single transposition of adjacent elements, the count of swaps gives a notion of inversions and hence a sign in any ring. Permutations are interconvertible with bijections of `Fin n` (via `EPerm`), and lift along arbitrary maps (and along injections in the converse direction), making them the bridge between combinatorial and equivalence-theoretic views of array reordering.

#### Core Data Type

- **`Perm`**: Permutation between `l1 l2 : Array A n`, generated by `perm-nil` (empty), `perm-::` (cons with equal heads), `perm-swap` (swap of two adjacent elements with tails equal), and `perm-trans` (transitivity).

#### Basic Operations

- **`perm-refl`**: Reflexivity `Perm l l`, built by induction on the length.
- **`perm-sym`**: Symmetry, inverting each constructor (head equality, swap equalities, and transitivity order).
- **`perm-map`**: Functoriality: a permutation `Perm l1 l2` lifts to `Perm (map f l1) (map f l2)` along any `f : A -> B`.
  - **`perm-map.conv`**: Converse for injective `f` between sets — descends a permutation of mapped arrays back to the originals via `perm_equiv`.

#### Inversions and Sign

- **`inversions`**: Number of swap constructors used (0 for `perm-nil`/`perm-::`, 1 for `perm-swap`, additive over `perm-trans`).
- **`inversions_perm-::`**, **`inversions_perm-trans`**, **`inversions_perm-refl`**: Computational lemmas that `inversions` ignores cons steps, distributes over transitivity, and vanishes on reflexivity.
- **`sign`**: The sign of a permutation in a ring `R`, defined as `(-1)^(inversions p)`.

#### Removal and Fin Permutations

- **`perm-remove`**: For `l : Array A (suc n)` and index `j`, produces `Perm l (l j :: remove1 (l j) l)`, moving the `j`-th element to the front (over a `DecSet`).
- **`perm-fin`**: Any injective `l : Array (Fin n) n` is a permutation of the identity array `\lam j => j`. Proved via the pigeonhole principle to find a preimage of `0`, then recursing on the smaller array obtained by removal and `fpred`.
  - **`perm-fin.aux`**, **`perm-fin.aux2`**: Helpers handling the inductive step (shifting via `fsuc`/`fpred`) and the splitting at `0`.

#### Bijection Correspondence

- **`equiv_perm`**: From an equivalence `e : Equiv {Fin n} {Fin n}`, produces `Perm l (\lam j => l (e j))`, exhibiting array reordering by a bijection as a permutation.
- **`perm_equiv`**: Conversely, extracts from a `Perm l l'` an equivalence `e` together with witnesses `l' j = l (e j)`, going through `EPerm` (the equivalence-presented permutation type) via `Perm_EPerm` and `eperm_equiv`.
  - **`perm_equiv.conv`**: Inverse direction — turns a bijection-with-witnesses pair back into a `Perm l l'` by transport along function extensionality.
