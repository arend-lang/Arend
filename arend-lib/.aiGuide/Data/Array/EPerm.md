### Data.Array.EPerm

Equivalence-based permutations of arrays, allowing rearrangement up to pointwise equality.

This module defines `EPerm`, an inductive relation expressing that two arrays are permutations of each other where corresponding elements are merely equal (rather than definitionally identical, as in `Perm`). The relation is generated by four constructors — empty, cons (with an equality on heads), adjacent swap (allowing equalities on the swapped pair), and transitivity — making it a flexible setoid-style permutation. The module proves `EPerm` is an equivalence relation, relates it to the stricter `Perm` via an equivalence of finite index sets, and shows interactions with common array operations (`++`, `map`, `filter`, `keep`/`remove`, `nub`). For decidable equality types, permutations are characterized by elementwise count equality and decidable as a relation.

#### Core Definition

- **`EPerm`**: Inductive permutation relation on arrays with constructors `eperm-nil`, `eperm-::` (cons with head equality), `eperm-swap` (adjacent transposition with element equalities), and `eperm-trans`.
- **`keep_remove-split`**: For decidable predicate `P`, the array is `EPerm`-equivalent to `keep P l ++ remove P l`.

#### Equivalence Structure

- **`eperm-refl`**: Reflexivity of `EPerm`.
- **`eperm-=`**: Path induction: `l = l'` implies `EPerm l l'`.
- **`eperm-sym`**: Symmetry: inverts the underlying equalities and the transitivity tree.
- **`EPerm-equivalence`**: `Equivalence` instance on `Array A` for `\lam l l' => TruncP (EPerm l l')`.

#### Concatenation Lemmas

- **`eperm-++-comm`**: Commutativity of `++` up to `EPerm`: `EPerm (l ++ l') (l' ++ l)`.
- **`eperm-++-left`**: `EPerm` is preserved by appending a fixed array on the right.
- **`eperm-++-right`**: `EPerm` is preserved by prepending a fixed array on the left.
- **`eperm-++`**: Congruence of `++` for `EPerm` on both arguments.
- **`EPerm_++-swap`**: `EPerm (l ++ a :: l') (a :: l ++ l')` — moves a singleton across an append.

#### Swap Helpers

- **`eperm-swap-trans`**: Swap-then-transitivity: prepends a swap to an existing permutation.
- **`eperm-swap-tail`**: Swap heads of `x :: y :: l` and `y :: x :: l'` given `EPerm l l'`.

#### Operations Preserving EPerm

- **`EPerm_map`**: `EPerm` is preserved by `map f`; the inner `conv` recovers `EPerm l l'` from `EPerm (map f l) (map f l')` for injective `f`.
- **`EPerm_keep`**, **`EPerm_remove`**: Compatibility with predicate-based filtering via `keep`/`remove`.
- **`EPerm_nub`**: Compatibility with deduplication on a `DecSet`.
- **`EPerm_filter`**: Compatibility with boolean `filter`.
- **`eperm-remove`**: For an injective array `l`, `EPerm l (l j :: removeElem (l j) l)` — extracts an element to the front.

#### Relation to `Perm`

- **`Perm_EPerm`**: Every (length-fixed) `Perm` gives an `EPerm`.
- **`EPerm_Perm`**: Conversely, an `EPerm` between equal-length arrays yields a `Perm`, via the underlying index equivalence.
- **`EPerm_Perm_transport`**: Transports an `EPerm` between arrays of differing lengths (along a length equality) into a `Perm`.
- **`eperm_equiv`**: Extracts the underlying `Equiv` between index sets `Fin l'.len ≃ Fin l.len` together with the pointwise equality `l' j = l (e j)`; uses `transposition1` for the swap case. The nested `conv` provides the converse construction.

#### Length, Decidability, and Counting

- **`EPerm_len`**: Permutations preserve length.
- **`EPermDec`**: Decidability of `EPerm` for `DecSet`-valued arrays, via finite search over index equivalences.
- **`EPerm_count`**: Permutations preserve elementwise occurrence counts.
- **`count_EPerm`**: Converse — equal counts at every element imply `EPerm` (proved by induction on a length bound, repeatedly extracting a chosen element via `keep_remove-split`).
