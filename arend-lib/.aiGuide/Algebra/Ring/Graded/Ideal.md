### Algebra.Ring.Graded.Ideal

Homogeneous ideals in graded commutative rings.

This module defines ideals that are compatible with a grading: an ideal `I` is homogeneous when, whenever a sum of homogeneous elements lies in `I`, every summand also lies in `I`. The formalization provides two equivalent perspectives — the closure-under-homogeneous-summands axiom, and existence of a homogeneous generating set — and supplies translation functions between them. The irrelevant ideal (generated by elements of positive degree) is constructed as a canonical example via the generator-based interface.

#### Main Record

- **`HomogenIdeal`**: A homogeneous ideal in a `GradedCRing`, extending `Ideal` with the field `isHomogenIdeal`: for any homogeneous array `l` whose `BigSum` lies in the ideal, every entry of `l` lies in the ideal.

#### Equivalent Generator-Based Characterization

- **`HomogenIdeal.hasHomogenGen`**: For an `Ideal I` of a `GradedCRing R`, the data of a subset `U : R -> \Prop` such that every `U`-element is homogeneous (of some degree) and `I` coincides with the ideal closure `Ideal.sclosure U`.
- **`HomogenIdeal.toGen`**: Extracts a homogeneous generating set from a `HomogenIdeal`, taking `U` to be the family of single homogeneous summands appearing in decompositions of elements of the ideal.
- **`HomogenIdeal.fromGen`**: Builds a `HomogenIdeal` from any `Ideal I` together with a truncated witness that `I` admits a homogeneous generating set (proof of `isHomogenIdeal` left as a hole `{?hidden_proof}`).

#### Examples

- **`irrelevantIdeal`**: The irrelevant ideal of a `GradedCRing R`, namely the ideal generated by all elements that are homogeneous of strictly positive degree. Constructed via `HomogenIdeal.fromGen` using the generating set `∃ (n : Nat) (isHomogen x (suc n))`.
