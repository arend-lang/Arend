### Algebra.Ring.QPoly

Polynomials over an `AddPointed` represented as a quotient of coefficient arrays modulo trailing zeros.

#### Core Type

- **`QPoly`**: Polynomials over `R : AddPointed`, defined as `Quotient {Array R}` where two arrays are identified if one extends the other by a trailing `0`.

#### Equivalence Relation on Arrays

- **`~`**: Data type expressing the equivalence on `Array R` generated by appending zeros, with constructors `eq-left n` (right side has `n` extra trailing zeros) and `eq-right n` (left side has `suc n` extra trailing zeros).
- **`~.lists-lem1`**: Uniqueness of the padding length: if `l ++ replicate n zro = l'` and `l ++ replicate m zro = l'`, then `n = m`.
- **`~.lists-lem2`**: Incompatibility lemma: padding `l` to `l'` and padding `l'` (by at least one zero) to `l` is impossible.
- **`~.levelProp`**: Proves that `l ~ l'` is a proposition.

#### Equivalence Structure

- **`~-isEquiv`**: Instance of `Equivalence (Array R)` for `~`, supplying reflexivity (via `eq-left 0`), symmetry, and transitivity by case analysis on the constructors.
- **`~-isEquiv.symm`**: Symmetry of `~`.
- **`~-isEquiv.lists-lem1`**: From `x ++ replicate n zro = z ++ replicate m zro` with `m <= n`, derives `x ~ z`.
- **`~-isEquiv.lists-lem2`**: From `y ++ replicate n zro = x`, `y ++ replicate m zro = z`, and `n <= m`, derives `x ~ z`.

#### Quotient Reflection

- **`from=to~`**: Reflects equality in `QPoly R` back to the relation `~` on arrays.
- **`from~to=`**: Lifts `l ~ l'` to equality `in~ l = in~ l'` in `QPoly R`.

#### Polynomial Construction

- **`qadd`**: Prepends a coefficient `e : R` to a polynomial `p : QPoly R`, defined by recursion on the quotient and respecting `~`.

#### Inversion Lemmas

- **`nil_cons`**: If `in~ nil = in~ (e :: l)` in `QPoly R`, then `e = zro` and `in~ nil = in~ l`.
- **`qadd_nil`**: If `qadd p e = in~ nil`, then `p = in~ nil` and `e = 0`.
- **`qadd_cons`**: If `qadd p e = in~ (a :: l')`, then `e = a` and `p = in~ l'`.
