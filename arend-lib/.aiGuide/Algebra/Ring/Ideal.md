### Algebra.Ring.Ideal

Defines left, right, two-sided, and commutative ring ideals, together with constructions (closures, generated ideals, principal ideals, unions, products) and the lattice/monoid structure on the set of ideals.

#### Ideal Classes

- **`LIdeal`**: Left ideal of a ring; extends `SubAddGroup` with `ideal-left : contains a -> contains (r * a)`. Negative-closure is derived from left-multiplication by `-1`.
- **`RIdeal`**: Right ideal; extends `SubAddGroup` with `ideal-right : contains a -> contains (a * r)`.
- **`TIdeal`**: Two-sided ideal; extends both `LIdeal` and `RIdeal`.
- **`Ideal`**: Ideal of a commutative ring `CRing`; extends `TIdeal`, deriving `ideal-right` from `ideal-left` via commutativity.

#### Closure Constructions

- **`Ideal.closure`**: Ideal generated by a family `g : J -> R`; elements are finite sums `∑ cᵢ * g jᵢ`.
- **`Ideal.sclosure`**: Ideal generated by a subset `U : R -> \Prop`, defined as `closure` over `\Sigma (x : R) (U x)`.
- **`closure-superset`**, **`sclosure-superset`**: Each generator lies in the closure.
- **`closure-univ`**, **`sclosure-univ`**: Universal property — any ideal containing the generators contains the closure.
- **`closure1`**: Principal ideal `(a)` generated by a single element `a : R`.
- **`closure1-lem`**: `b ∈ (a)` iff `∃ c, b = a * c`.
- **`closure1_LDiv`**: `b ∈ (a)` iff `a` left-divides `b`.
- **`closure1-principal`**: `closure1 a` is a principal ideal (with `generated`: it is generated by `a`).

#### Closure Membership Lemmas

- **`closure2-lem`**: Membership in a 2-element closure: `a ∈ closure f` iff `∃ c d, a = f true * c + f false * d`.
- **`fin-closure-lem`**: For finite index sets `D`, membership is characterized by `FinSum`.
- **`closureN-lem`**: For an array `B`, `a ∈ closure B` iff `a = ∑ cᵢ * Bᵢ` for some array `c` of the same length.
  - **`singleton-lem`**: `∑ⱼ (if i == j then a else 0) = a`.
  - **`suc-eq`**: `suc a == suc b = a == b` (Nat equality decision).
- **`closure-generated`**: The closure of an array `l` is generated by `l`.
- **`closure-finGenerated`**: The closure of an array is finitely generated.

#### Chain Conditions and Unions

- **`ChainCondition`**: For an ascending chain `I : Nat -> Ideal R`, asserts that some `I (suc n) ⊆ I n` (i.e., the chain stabilizes).
- **`fromMonoidChainCondition`**: Derives the ideal chain condition from a divisibility chain condition on `DivQuotientMonoid R`, given that each ideal in the chain is principal.
- **`Ideal.union`**: Ideal-theoretic union of an ascending chain `I : Nat -> Ideal R` (with inclusion proofs); membership is `∃ n, I n a`.
  - **`union.include`**: Inclusion `I n a -> I (n + m) a` along the chain.

#### Maximal Ideals

- **`countable-maximal`**: For a countable commutative ring `R` with decidable membership in finitely generated ideals, every proper finitely generated ideal `I` is contained in a maximal ideal `M`. Constructed by enumerating `R` and greedily extending the ideal element-by-element.
  - **`countable-maximal.next`**: One step of the greedy construction — extends ideal `I` by adjoining the `n`-th element of `R`.
  - **`countable-maximal.next-fg`**: The extended ideal is finitely generated.
  - **`countable-maximal.ideal`**: The chain of ideals built by the greedy procedure.
  - **`countable-maximal.ideal-proper`**: Each ideal in the chain is proper (does not contain `1`).

#### Lattice Structure

- **`IdealLattice`**: `BoundedLattice (Ideal R)` for a commutative ring `R`. Order is set-theoretic inclusion; `meet` is intersection; `join I J` is the closure of `I ∪ J`; `top` is the unit ideal; `bottom` is the zero ideal.

#### Monoid (Product) Structure

- **`IdealMonoid`**: `CMonoid (Ideal R)` with the ideal product `I * J` as multiplication and the unit ideal as identity. Commutativity, associativity, and unit laws are proved via the closure universal property.
- **`IdealMonoid.func`**: The pairing `(a, b, _, _) ↦ a * b` used as generators.
- **`IdealMonoid.product`**: Product ideal `I * J = closure (func I J)`, generated by products `a * b` with `a ∈ I`, `b ∈ J`.
- **`product-left`**, **`product-right`**: `I * J ⊆ I` and `I * J ⊆ J`.
- **`product_meet`**: `I * J ⊆ I ∧ J` (the product is contained in the intersection).
