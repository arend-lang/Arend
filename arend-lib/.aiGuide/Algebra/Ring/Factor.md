### Algebra.Ring.Factor

Quotient rings by ideals, with specializations to fields when the ideal is maximal or generated by an irreducible element.

This module constructs the factor ring `R/I` as a quotient of the carrier of `R` by the equivalence relation `a ~ b ⟺ a - b ∈ I`, packaged as a `CRing` instance. The canonical projection `factorHom` and its universal property `factor-lift` (lifting any ring hom that vanishes on `I`) give the standard quotient API. Two specializations show when the quotient is a field: `FactorField` gives `R/m` for maximal `m`, and `FactorIrrField` gives `R/(p)` for an irreducible `p` in a Bézout ring, with a converse lemma characterizing primes via the field structure on the quotient.

#### Factor Ring Construction

- **`FactorRing`**: Commutative ring instance `R/I` for an ideal `I`, with carrier `Quotient` of `I.S` modulo `a ~ b ⟺ I (a - b)`. Defines addition, multiplication, negation, and constants on equivalence classes, using ideal closure properties to verify well-definedness.
- **`FactorRing.Type`**: Underlying type of the factor ring as a `Quotient`.
- **`FactorRing.inF`**: Canonical inclusion `I.S -> FactorRing I` sending `a` to its equivalence class `in~ a`.
- **`FactorRing.fequiv`**: From `I (a - b)`, deduces `inF a = inF b` in the quotient.
- **`FactorRing.fequiv0`**: From `I a`, deduces `inF a = inF 0`.
- **`FactorRing.unfequiv`**: Inverse of `fequiv`: from `inF a = inF b`, recovers `I (a - b)`.
- **`FactorRing.unfequiv0`**: Inverse of `fequiv0`: from `inF a = inF 0`, recovers `I a`.

#### Quotient Homomorphisms

- **`factorHom`**: The canonical ring homomorphism `R -> R/I` sending each element to its class via `inF`.
- **`factor-lift`**: Universal property of the quotient: given a ring hom `f : R -> R'` that vanishes on `I` (i.e. `I a -> f a = 0`), produces the unique induced ring hom `R/I -> R'`.

#### Factor Fields

- **`FactorField`**: `DiscreteField` instance on `R/I` when `I` is a maximal ideal (`I.IsMaximal`).
- **`FactorField.conv`**: Converse: if `R/I` is a discrete field (witnessed by `0 /= 1` and the dichotomy `x = 0 ∨ Inv x`), then `I` is maximal.
- **`FactorIrrField`**: `DiscreteField` instance on `R/(p)` for an irreducible element `p` of a Bézout ring `R`, using the principal ideal `Ideal.closure1 p`.
- **`FactorIrrField.trivial_Inv`**: `0 = 1` in `R/(p)` iff `p` is a unit; characterizes when the quotient is trivial.
- **`FactorIrrField.zeroOrInv-char`**: The field dichotomy on `R/(p)` is equivalent to: every `a : R` is either divisible by `p` or admits a Bézout combination `s * a + t * p = 1`.
- **`FactorIrrField.conv`**: Converse direction: if multiplication by `p` is cancellative and `R/(p)` is a discrete field, then `p` is prime.
