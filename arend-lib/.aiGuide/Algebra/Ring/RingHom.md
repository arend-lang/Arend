### Algebra.Ring.RingHom

Homomorphisms of (semi)rings, their kernels, and the canonical maps from `Nat` and `Int`.

This module layers ring homomorphisms on top of the additive and multiplicative monoid/group homomorphism records: a `SemiringHom` combines `AddMonoidHom` with `MonoidHom`, a `PseudoRingHom` combines `AddGroupHom` with `SemigroupHom`, and a `RingHom` extends both so kernels become two-sided ideals. The `\where` block provides identity, composition, and equality-by-extensionality, plus the universal maps `natMap` and `intMap` from `NatSemiring` and `IntRing`, which let any ring be regarded as an algebra over `Nat`/`Int`. Notions of finite/algebraic generation (`isAlgebraGenerated`, `isFiniteAlgebra`) are formulated via multivariate polynomial evaluation through `f`.

#### Auxiliary Multiplication Homomorphisms

- **`*-addMonoidHom-left`**: For a pseudo-semiring `R` and `a : R`, left multiplication `a *` is an additive monoid homomorphism.
- **`*-addMonoidHom-right`**: Right multiplication `* a` is an additive monoid homomorphism.
- **`*-addGroupHom-left`**: In a pseudo-ring, `a *` is an additive group homomorphism.
- **`*-addGroupHom-right`**: In a pseudo-ring, `* a` is an additive group homomorphism.

#### Semiring Homomorphisms

- **`SemiringHom`**: Record extending `AddMonoidHom` and `MonoidHom` between semirings; a map preserving `+`, `0`, `*`, and `1`.
- **`SemiringHom.func-natCoef`**: A semiring homomorphism commutes with the canonical `Nat` coefficient embedding: `func (natCoef n) = natCoef n`.

#### Pseudo-ring Homomorphisms

- **`PseudoRingHom`**: Record extending `AddGroupHom` and `SemigroupHom` between pseudo-rings; a map preserving `+` and `*`.

#### Ring Homomorphisms

- **`RingHom`**: Record extending `PseudoRingHom` and `SemiringHom` between rings; the principal abstraction of the module.
- **`RingHom.Kernel`**: The kernel as a two-sided ideal `TIdeal Dom`, whose underlying additive subgroup is the kernel `KernelAddGroup` of the additive group homomorphism, closed under multiplication on both sides.

#### Identity, Composition, and Equality

- **`RingHom.equals`**: Pointwise equality of ring homomorphisms suffices for equality (extensionality).
- **`RingHom.id`**: The identity ring homomorphism `RingHom R R`.
- **`RingHom.compose` / `RingHom.∘`**: Composition of ring homomorphisms `g ∘ f : RingHom R T` from `f : RingHom R S` and `g : RingHom S T`.

#### Universal Properties

- **`RingHom.contr-isTerm`**: If `S` is contractible, then `RingHom R S` is contractible — contractible rings are terminal in `Ring`.
- **`RingHom.field-isInj`**: Any ring homomorphism from a field `K` to a non-zero ring is injective.

#### Algebra Generation

- **`RingHom.isAlgebraGenerated`**: Predicate that an array `l : Array E` generates `E` as an `R`-algebra along `f : RingHom R E`: every `x : E` is the evaluation at `l` of a multivariate polynomial over `R`.
- **`RingHom.isFiniteAlgebra`**: `f` makes `E` a finitely generated `R`-algebra (existence of such an `l`).
- **`RingHom.isAlgebraGenerated-comp`**: If `E` is generated over `R` by a single element `a` (via univariate polynomials) and `S` is generated over `E` by `l`, then `S` is generated over `R` by `g a :: l` along `g ∘ f`.
- **`RingHom.isAlgebraGenerated-poly`**: A single element `a : E` whose orbit under `f` covers all of `E` makes `f` generated by `a :: nil`.

#### Commutative Variants

- **`RingHom.KernelC`**: Kernel of a homomorphism out of a commutative ring, packaged as an `Ideal R`.

#### Canonical Maps from Nat and Int

- **`natMap`**: The unique semiring homomorphism `SemiringHom NatSemiring R` for any semiring `R`, given by `natCoef`.
- **`natComm`**: Elements coming from `Nat` commute with everything: `natMap n * x = x * natMap n`.
- **`intMap`**: The unique ring homomorphism `RingHom IntRing R` for any ring `R`, given by `intCoef`.
- **`intMap.intCoef_diff`**: Compatibility of `intCoef` with the natural-number difference: `intCoef (n Nat.- m) = intCoef n - intCoef m`.
- **`intComm`**: Elements coming from `Int` commute with everything: `intMap n * x = x * intMap n`.
