### Algebra.Ring.RingHom

Homomorphisms between (semi)rings and rings, including identity, composition, and the canonical maps from `Nat` and `Int`.

#### Multiplication as Additive Homomorphisms

- **`*-addMonoidHom-left`**: Left multiplication `(a *)` is an `AddMonoidHom` for a `PseudoSemiring`.
- **`*-addMonoidHom-right`**: Right multiplication `(* a)` is an `AddMonoidHom` for a `PseudoSemiring`.
- **`*-addGroupHom-left`**: Left multiplication `(a *)` is an `AddGroupHom` for a `PseudoRing`.
- **`*-addGroupHom-right`**: Right multiplication `(* a)` is an `AddGroupHom` for a `PseudoRing`.

#### Homomorphism Classes

- **`SemiringHom`**: Homomorphism between semirings; extends `AddMonoidHom` and `MonoidHom` with `Dom`, `Cod : Semiring`.
- **`RingHom`**: Homomorphism between rings; extends `SemiringHom` and `AddGroupHom` with `Dom`, `Cod : Ring`.

#### Ring Homomorphism Operations

- **`RingHom.equals`**: Extensionality: pointwise equality of ring homomorphisms implies equality.
- **`RingHom.id`**: Identity ring homomorphism `R -> R`.
- **`RingHom.compose`** (`∘`): Composition of ring homomorphisms; preserves `func-ide`, `func-+`, `func-*`.
- **`RingHom.contr-isTerm`**: A contractible ring `S` is terminal: `RingHom R S` is contractible.
- **`RingHom.field-isInj`**: Any ring homomorphism from a field `K` to a non-zero ring `R` is injective.

#### Algebras and Generation

- **`RingHom.isAlgebraGenerated`**: Predicate stating that an array `l : Array E` generates `E` as an `R`-algebra via `f : RingHom R E`, i.e., every `x : E` is the evaluation of some multivariate polynomial over `R` at `l`.
- **`RingHom.isFiniteAlgebra`**: `f : RingHom R E` makes `E` a finitely generated `R`-algebra (some array generates it).
- **`RingHom.isAlgebraGenerated-comp`**: If `f : R -> E` is generated by a single element via univariate polynomials and `g : E -> S` is generated by `l`, then `g ∘ f` is generated by `g a :: l`.
- **`RingHom.isAlgebraGenerated-poly`**: If every element of `E` is a univariate polynomial in `a` over `R`, then `f` is algebra-generated by `a :: nil`.

#### Kernels and Images (Commutative Case)

- **`RingHom.KernelC`**: Kernel of a ring homomorphism into a commutative ring, packaged as an `Ideal`.
- **`RingHom.ImageC`**: Image of a ring homomorphism into a commutative ring, packaged as a `CSubRing`.

#### Canonical Maps from Nat and Int

- **`natMap`**: Canonical `SemiringHom` from `NatSemiring` into any semiring `R`, given by `natCoef`.
- **`natComm`**: Image of a natural number under `natMap` commutes with every element: `natMap n * x = x * natMap n`.
- **`intMap`**: Canonical `RingHom` from `IntRing` into any ring `R`, given by `intCoef`.
- **`intMap.intCoef_diff`**: `intCoef (n - m) = intCoef n - intCoef m` in any ring.
- **`intComm`**: Image of an integer under `intMap` commutes with every element: `intMap n * x = x * intMap n`.
