### Algebra.Ring.Nakayama

Nakayama's lemma and its corollaries for finitely generated modules over commutative rings.

This module formalizes the classical Nakayama lemma, which provides a powerful tool for reasoning about finitely generated modules annihilated by an ideal. The central idea is that if a finitely generated module `M` satisfies `M ⊆ I·M` for some ideal `I`, then there exists a ring element `e` congruent to `1` modulo `I` that annihilates `M`. The proof typically proceeds via a determinant trick using the Cayley–Hamilton theorem on a matrix expressing the generators of `M` in terms of `I·M`. Corollaries include the idempotent generation of self-square ideals and a finite-dimensional analogue of the surjective-implies-bijective principle for endomorphisms.

#### Nakayama's Lemma

- **`nakayama`**: For a finitely generated module `M` over a commutative ring `R` with `M ⊆ I·M`, produces an element `e : R` with `1 - e ∈ I` such that `e·m = 0` for all `m : M`.
- **`nakayama'`**: Dual form: produces `e ∈ I` such that `e·m = m` for all `m : M` (i.e., `e` acts as identity on `M`).

#### Corollaries

- **`nakayama-ideal`**: For a finitely generated ideal `I` with `I ⊆ I²`, produces an idempotent `u : R` (`u·u = u`) such that `I` is principal, generated by `u`.
- **`linear-surj-equiv`**: For a finitely generated module `U`, any surjective linear endomorphism `f : U → U` is an equivalence (i.e., automatically injective).
