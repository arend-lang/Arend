### Relation Directory Overview

Theory of relations, equivalence relations, quotients, and closures.

- **`Equivalence.md`**: `Transitive` and `Equivalence` classes, transitive/equivalence closures, `Quotient` HIT with surjectivity, equality characterization, functorial map, array lifting, `SubQuotient`, `QuotientDec`.
- **`Truncated.md`**: Propositionally truncated closures — `transitive-closure`, `transitive-refl-closure`, `symmetric-closure`, `reflexive-closure`.
