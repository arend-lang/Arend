### Relation.Truncated

Propositionally truncated relations and their standard closures.

This module defines `Rel A` as a `\Prop`-valued binary relation on a set, then provides the four classical closure operations as inductive datatypes that automatically live in `\Prop`. Each closure is generated by minimal constructors capturing the defining clauses (direct relation, reflexivity, transitivity step, symmetry), so proofs by induction reduce to handling these cases. The transitive-reflexive closure additionally exposes convenience constructors for unary and reflexive use.

#### Relation Type

- **`Rel`**: `Rel A` is `A -> A -> \Prop`, the type of propositional binary relations on a set.

#### Transitive Closure

- **`transitive-closure`**: Inductive `\Prop` defining the transitive closure of `R`.
  - **`tc-direct`**: Embed a direct relation `a R b`.
  - **`tc-connect`**: Extend by a step: from `a R c` and `transitive-closure R c b` build `transitive-closure R a b`.

#### Transitive-Reflexive Closure

- **`transitive-refl-closure`**: Inductive `\Prop` defining the reflexive-transitive closure of `R`.
  - **`trc-direct`**: Reflexivity from a path `a = b`.
  - **`trc-connect`**: Prepend a relation step `a R c` to a closure `c ~>* b`.
- **`trc-unary`**: Lifts a single `a R b` into the closure via `trc-connect b p (trc-direct idp)`.
- **`trc-direct'`**: Pure reflexivity `transitive-refl-closure R a a` from `idp`.

#### Symmetric Closure

- **`symmetric-closure`**: Inductive `\Prop` for the symmetric closure.
  - **`sc-left`**: Witness from `a R b`.
  - **`sc-right`**: Witness from `b R a`.

#### Reflexive Closure

- **`reflexive-closure`**: Inductive `\Prop` for the reflexive closure.
  - **`rc-id`**: Reflexivity from `a = b`.
  - **`rc-rel`**: Embed a direct relation `a R b`.
