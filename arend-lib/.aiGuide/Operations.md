### Operations (root file)

Type-level product and coproduct operations.

- **`HasProduct`**: Class with `E : \hType` and `Product` (alias `⨯`).
- **`TypeHasProduct`**: Instance for `\Type` with `Product = \Sigma`.
- **`HasCoproduct`**: Class with `E : \hType` and `Coproduct` (alias `⨿`).
- **`TypeHasCoproduct`**: Instance for `\Type` with `Coproduct = Or`.
